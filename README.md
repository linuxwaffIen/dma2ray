# Govno VPN (Client)

Графический клиент для управления подключениями VLESS на базе **Xray-core**. Написан на Python, а интерфейс создан с использованием GTK4.

## Возможности

- Три режима работы:
  - **Прокси** — проксирование трафика приложений, настроенных на локальный прокси.
  - **Системный прокси** — использование прокси на уровне системных настроек.
  - **VPN** — маршрутизация трафика через VPN-режим.
- Добавление профилей вручную и импорт подписок.
- Отображение скорости соединения и задержки.
- Журнал событий Xray-core.
- Тёмная тема интерфейса.
- kal в стакане 

## Совместимость

Клиент использует Xray-core, поэтому его можно адаптировать для разных архитектур, если для целевой платформы доступна подходящая сборка ядра и необходимые зависимости.

Для VPN-режима могут потребуются права доступа (root) — это зависит от операционной системы (govna) и способа запуска приложения.
