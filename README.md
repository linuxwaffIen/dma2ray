Графический клиент для управления подключениями **VLESS** на базе **Xray-core**. Написан на Python, интерфейс — на GTK4.

## Возможности

- Три режима работы:
  - **Прокси** — проксирование трафика приложений, настроенных на локальный прокси.
  - **Системный прокси** — прокси на уровне системных настроек.
  - **VPN** — маршрутизация трафика через VPN-режим.
- Добавление профилей вручную и импорт подписок.
- Отображение скорости соединения и задержки.
- Журнал событий Xray-core.
- Тёмная тема интерфейса.

## Совместимость

Клиент использует Xray-core, поэтому его можно адаптировать под разные архитектуры: достаточно подходящей сборки ядра и необходимых зависимостей для целевой платформы.

Для VPN-режима требуются права суперпользователя (root). Способ их получения зависит от операционной системы и того, как запускается приложение.
